# Child-checked story words

One file per night, named by the night's slug. When the nightly build finds a file here for the night it is building, the `p1` (three paragraphs, first story page) and `p2` (two paragraphs, second story page) replace the PDF's story paragraphs everywhere: the story book, and the story card of both editions (Christian reads God). `old_p1`/`old_p2` are the PDF's words, kept so the printed book can be matched. See HANDOFF §40 (the Child's Story Rule).
